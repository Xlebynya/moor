## Установка проекта

```sh
npm i

npm run lint

npm run dev //Compile and Hot-Reload for Development

npm run build //Type-Check, Compile and Minify for Production
```

## О проекте

Проект на vue, бэкенд на момент написания этого текста реализован файлами `.json` и `.md` файлами в этом же проекте папке public
